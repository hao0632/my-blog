b:T85ad,<h2 id="一-ai安全概述">一、AI安全概述</h2>
<p>AI安全是CTF中新兴的重要题目类别，主要考察选手对机器学习模型安全、深度学习系统漏洞和AI系统攻防的理解。随着AI技术的普及，AI安全题目在CTF比赛中的比重逐渐增加，涵盖从传统机器学习到大型语言模型（LLM）的各种攻击场景。</p>
<p><strong>核心能力要求：</strong></p>
<ul>
<li>理解机器学习模型的工作原理</li>
<li>掌握对抗攻击的基本方法</li>
<li>熟悉常见的模型漏洞和攻击向量</li>
<li>了解LLM的安全特性和提示注入技术</li>
</ul>

<h2 id="二-对抗样本攻击">二、对抗样本攻击</h2>
<h3 id="2-1-图像对抗样本">2.1 图像对抗样本</h3>
<p><strong>核心考点：FGSM、PGD、DeepFool等攻击方法，模型规避检测</strong></p>
<ol>
<li>
<p><strong>基础概念</strong></p>
<ul>
<li>对抗样本：在原始输入上添加微小扰动，使模型做出错误预测</li>
<li>扰动通常人眼不可察觉，但能显著改变模型输出</li>
<li>攻击目标：分类错误、目标类别误导、置信度降低</li>
</ul>
</li>
<li>
<p><strong>常见攻击方法</strong></p>
</li>
</ol>
<table>
<thead>
<tr>
<th>攻击方法</th>
<th>原理</th>
<th>特点</th>
</tr>
</thead>
<tbody>
<tr>
<td>FGSM</td>
<td>Fast Gradient Sign Method，利用梯度符号生成扰动</td>
<td>快速高效，单次迭代</td>
</tr>
<tr>
<td>PGD</td>
<td>Projected Gradient Descent，多次迭代优化扰动</td>
<td>更强的攻击效果</td>
</tr>
<tr>
<td>DeepFool</td>
<td>寻找最小扰动使样本跨越决策边界</td>
<td>最小扰动攻击</td>
</tr>
<tr>
<td>CW</td>
<td>Carlini-Wagner攻击，优化特定目标函数</td>
<td>高成功率，复杂计算</td>
</tr>
<tr>

<h3 id="2-2-语音对抗样本">2.2 语音对抗样本</h3>

<li><strong>针对性攻击</strong>：针对特定语音识别模型进行优化攻击</li>

<h2 id="十-常见坑与技巧">十、常见坑与技巧</h2>
<h3 id="10-1-对抗样本的可迁移性">10.1 对抗样本的可迁移性</h3>
<p><strong>问题：</strong> 在一个模型上生成的对抗样本可能无法攻击另一个模型</p>
<p><strong>解决方法：</strong></p>
<ul>
<li>训练多个模型，生成通用对抗样本</li>
<li>使用集成攻击方法</li>
<li>增加扰动幅度提高可迁移性</li>
</ul>
<h3 id="10-2-api调用限制">10.2 API调用限制</h3>
<p><strong>问题：</strong> 模型提取攻击受限于API调用次数</p>
<p><strong>解决方法：</strong></p>
<ul>
<li>使用主动学习策略选择最有价值的样本</li>
<li>利用模型的对称性减少查询次数</li>
<li>使用合成数据补充真实查询</li>
</ul>
<h3 id="10-3-llm安全防护">10.3 LLM安全防护</h3>
<p><strong>问题：</strong> 提示注入攻击可能被安全机制检测</p>
<p><strong>解决方法：</strong></p>
<ul>
<li>使用编码技术（Base64、Unicode）隐藏指令</li>
<li>尝试多模态输入绕过文本过滤</li>
<li>使用角色扮演和间接提问</li>
</ul>
<h3 id="10-4-验证码更新">10.4 验证码更新</h3>
<p><strong>问题：</strong> 验证码系统可能更新，旧的识别方法失效</p>
<p><strong>解决方法：</strong></p>
<ul>
<li>保持验证码识别模型的更新</li>
<li>使用通用的识别方法</li>
<li>结合多种识别策略</li>
</ul>
