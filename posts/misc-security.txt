<p>3.Hashcat
.\hashcat [选项]... &#x3C;哈希文件> [字典/掩码/目录]...</p>
<p>核心选项：
-m &#x3C;num>：哈希类型（0=MD5，1000=NTLM）。
-a &#x3C;num>：攻击模式（0=字典）。
-o &#x3C;file>：输出破解结果。
--show：显示已破解哈希。
-V：版本；-h：帮助。
完整帮助：hashcat -h | grep &#x3C;关键词>。</p>
<p>0=MD5	100=SHA1	1000=NTLM	3200=bcrypt	17220=ZIP	22000=WPA2	13000=rar
查询：hashcat -h | grep ZIP。</p>
<p>4.1 直攻/字典攻击 (-a 0)

带规则：hashcat -m 0 -a 0 hashes.txt rockyou.txt -r rules/best64.rule</p>
<p>4.2 组合攻击 (-a 1)
合并两个词典生成多词密码（如 “admin” + “123” = “admin123”）。</p>
<p>命令：hashcat -m 0 -a 1 hashes.txt dict1.txt dict2.txt</p>
<p>4.3 暴力/掩码攻击 (-a 3)
尝试所有组合。使用占位符：
占位符	字符集
?l	a-z
?u	A-Z
?d	0-9
?s	符号
?a	全 ASCII
?h	十六进制小写
示例：hashcat -m 13000 -a 3 hash.txt nsfocus?d?d?d?d?d
增量：-i --increment-min=4 --increment-max=8（长度 4-8）。
4.4 混合攻击 (-a 6/7)
字典 + 掩码 (-a 6)：词典后缀掩码。如：hashcat -m 0 -a 6 hashes.txt rockyou.txt ?d?d
掩码 + 字典 (-a 7)：前缀词典。</p>

<h3 id="哥斯拉流量">哥斯拉流量</h3>
<p><strong>通用连接特征：</strong></p>
<ul>
<li>哥斯拉在进行初始化时会产生一个较大的数据包（第一个），后续操作产生的数据包则相对较小</li>
<li>第一个请求包的http响应体一般是空的</li>
<li>Cookie最后出现分号（可能没有）</li>
<li>Accept字段（弱特征）默认是特定值</li>
</ul>
<p><strong>第二次请求特征：</strong></p>
<ul>
<li>会携带响应数据包设置的Cookie值</li>
<li>http响应体是一段相对固定长的串，长度为64个字节</li>
<li>可分为前16字节，中间32字节，结尾16字节</li>
</ul>
<p><strong>第三次请求特征：</strong></p>
<ul>
<li>前16个字节和最后的16个字节和第二响应包是一致的</li>
<li>后续包同样有这个特性</li>
</ul>
<p><strong>原因：</strong>
哥斯拉对响应报文格式的设计，一个32位的md5字符串会被拆分为两部分，分别放在base64编码数据的前后。</p>
<p><strong>关键参数：</strong></p>
<ul>
<li>xc为加密密钥</li>
<li>pass为解密密码</li>
</ul>
<p><strong>后门反连通道：</strong> tcp、http、dns、icmp......</p>
<p><strong>ekp版本解密操作：</strong>
返回包为单次base解密</p>

<h2 id="侧信道攻击">侧信道攻击</h2>
<p><strong>核心原理</strong>：程序在运行的时候，不同复杂度所用的时间和消耗的能量是不同的。侧信道攻击正是利用计算设备在执行加密操作时无意间泄露的物理信息来推断密钥或其他敏感数据。</p>
<p><strong>常见侧信道</strong>：功耗、时间、电磁辐射、声波等。</p>
<h3 id="能量轨迹">能量轨迹</h3>
<p>能量轨迹是指设备在执行加密操作时消耗的功率随时间变化的记录。通过分析能量轨迹，可以推测出设备在不同时间点上执行的操作，从而恢复加密数据。</p>
<h3 id="攻击分类">攻击分类</h3>

<tr>
<td>简单能量分析</td>
<td>SPA</td>
<td>通过观察单次加密操作的功耗曲线，直接推断设备的内部状态，需要攻击者具有一定的设备内部知识</td>
</tr>
<tr>
<td>差分能量分析</td>
<td>DPA</td>
<td>通过多次加密操作的功耗曲线，结合统计分析方法来推断敏感信息，对噪声更为鲁棒</td>
</tr>
